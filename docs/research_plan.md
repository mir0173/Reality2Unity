## 연구 목표
여러 시점에서 촬영한 사진으로 실제 공간을 복원하고, Unity에서 사용할 수 있는 Terrain과 Mesh를 생성한다. 

## 1. 단계별 실행 구조 정리

Colab에서 Drive를 연결하고 Python 명령을 실행한다. 파이프라인은 입력 준비, 복원, 평가, Mesh 생성, Unity 출력 순서로 나눈다. 각 단계의 설정과 결과를 저장해, 평가 기준이나 Mesh 설정을 바꿨을 때는 저장된 복원 결과부터 이어서 실행한다.

## 2. VGGT 복원 실험

Colab T4에서 사진 4장, 8장, 23장 순으로 입력을 늘린다. 4장과 8장 실행에서는 카메라 배치와 복원 형상을 확인하고 실행시간과 최대 VRAM 사용량을 기록한다. 23장 실행에서는 카메라 파라미터, 깊이맵, 신뢰도, 점군을 저장해 기존 COLMAP 결과와 비교할 자료를 확보한다.
카메라 배치 오류나 표면 누락이 반복되면 MASt3R를 추가 후보로 검토한다. 

## 3. 복원 품질 평가
같은 Terrace 사진 23장을 사용한 결과를 ETH3D 참조 좌표에 정렬하고, 같은 영역에서 정확도, 완전도, F1을 비교한다. 거리 기준은 2cm, 5cm, 10cm로 설정한다. 전체 점수와 함께 기존에 비어 있던 벽면과 바닥을 확인한다. 복원 방식은 표면 누락이 얼마나 줄었는지, 새로 생긴 오차는 어느 정도인지, 실행 비용을 감당할 수 있는지를 종합해 선택한다.

## 4. Unity 시연
바닥과 벽이 만나는 작은 구간을 첫 시연 대상으로 정한다. 관측된 지면은 16비트 RAW 높이맵으로 변환해 Terrain에 적용하고, 벽과 돌출 구조는 별도 Mesh로 가져온다. 두 결과에 같은 원점, 방향, 스케일을 적용하고 Unity에서 바닥과 벽이 맞닿는지 확인한다.
